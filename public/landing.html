How It Works

Up and running in 10 minutes.

No cloud setup. No subscriptions. Just download, install, and start marketing.

1
Download & Install
Run setup.ps1 on Windows. Automatically installs Node.js, sets up the database, and creates a desktop shortcut. Takes 2 minutes.
2
Add Your AI
Install Ollama for free local AI — or paste your Gemini API key (free tier) in Settings. Start generating content immediately, no credit card required.
3
Connect Platforms
Click Connect for each social platform in Settings. OAuth handles the authentication. Social-Nexus stores your tokens locally — never on external servers.
4
Start Marketing
Generate posts, schedule content, run email campaigns, optimize SEO, create images and videos — all from one beautiful interface.
