Set up your local AI

Social-Nexus runs on Ollama — a free, private AI that runs on your computer. Follow these steps once to get started.

1

Install Ollama

Download and run the Ollama installer for your system. It sets itself up automatically and starts running in the background — no account needed.

Open download page ↗
2

Make sure Ollama is running  Not detected

On Windows/macOS, Ollama starts on its own after installing. If the status above stays red, open a terminal and run this command, then leave that window open:

ollama serve
3

Download the AI model

We recommend a model based on your computer. You can change it below.

ollama pull llama3.2:3b
