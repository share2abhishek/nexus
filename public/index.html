How Social-Nexus writes for you
Local AI runs on this PC for free — your text never leaves your computer. Online AI (Gemini, Claude…) needs an API key and sends the text you ask about to that company. If Local AI is switched on but not running, an online service you have a key for is used instead. Create Post always tells you which one wrote the text. Local AI and the default model are shared by everyone on this PC; API keys are saved to your own account only.

⬇️ Install Ollama (one-time setup)
Step 1 — Download from ollama.com/download → install the Windows app
Step 2 — Open Command Prompt or PowerShell and run:
ollama pull llama3.2
Downloads the Llama 3.2 3B model (~2GB). Takes 2-5 minutes.
Step 3 — Come back here and click Check above — it should show green ✅
Default — only change if running on a different port or machine
