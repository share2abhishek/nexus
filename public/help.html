NEXUS Documentation

Complete guide to using NEXUS — your AI-powered one-stop digital marketing platform. Find step-by-step setup guides, feature documentation, and troubleshooting tips.

⚡ Quick Start

Get NEXUS running in under 10 minutes:

  1. Run the installer
    .\install\setup.ps1 (Windows, run as Administrator). Automatically installs Node.js and all dependencies.
  2. Open NEXUS
    Double-click the NEXUS shortcut on your Desktop, or run npm start in the NEXUS folder.
  3. Create your admin account
    Go to http://localhost:3000 → you'll be redirected to the login page. The first registered user becomes Super Admin.
  4. Set up free AI
    In Settings → Local AI (Ollama): install Ollama, pull llama3.2, enable it. Free forever.
  5. Connect social accounts
    Settings → Social Platforms → enter your API credentials → Connect each platform.
  6. Generate your first post
    AI Generate → type a prompt → click Generate → use in Compose → Post Now ✅

💾 Installation

Windows (Recommended)

# Run in PowerShell as Administrator
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\install\setup.ps1

# With Ollama local AI bundled:
.\install\setup.ps1 -InstallOllama

# Custom install path:
.\install\setup.ps1 -InstallPath "D:\NEXUS" -InstallOllama
ℹ️ The installer automatically downloads Node.js v20 LTS if it's not installed. Requires ~500MB disk space (+ 2GB per AI model).

Manual Installation

cd nexus
npm install
copy .env.example .env
npm start

🔐 First Login & Admin Account

NEXUS uses email + password authentication. The first user to register automatically becomes the Super Admin (👑).

✅ When you register as the first user, you'll see "👑 You are the Super Admin" message. This account controls all platform settings and user access.

Admin Capabilities

  • Monitor all users — see post counts, AI usage, last active time
  • Manage user roles — promote/demote between Admin and User
  • Suspend/activate accounts — suspended users can't log in
  • Generate invite codes — for invite-only registration mode
  • View activity log — all posts across all users
  • Control registration — Open, Invite Only, or Closed

🤖 Setting Up AI

Option 1: Free Local AI with Ollama Recommended

  1. Download Ollama from ollama.com/download and install it.
  2. Open PowerShell and run: ollama pull llama3.2 (downloads ~2GB)
  3. In NEXUS: Settings → 🦙 Local AI → Check → Enable → Save
💡 Best Ollama models for marketing content: llama3.2 (fast, 2GB), mistral (best writing, 4GB), llama3.1:8b (highest quality, 5GB)

Option 2: Google Gemini Free Tier Available

  1. Go to aistudio.google.com → Sign in → Get API Key
  2. In NEXUS: Settings → 🤖 AI Keys → paste your key → Save

Option 3: Anthropic Claude API Key Required

  1. Go to console.anthropic.com → Create API Key
  2. In NEXUS: Settings → 🤖 AI Keys → Anthropic Claude → paste → Save

AI Priority Order

NEXUS tries AI providers in this order, falling back if unavailable:

  1. Ollama (if enabled and running)
  2. Google Gemini (if GOOGLE_AI_KEY is set)
  3. Anthropic Claude (if ANTHROPIC_API_KEY is set)

✏️ Compose & Post

The Compose page lets you write content and publish immediately or schedule for later.

  • Write or paste your content (or use AI Generate and click → Compose)
  • Select platforms by clicking the platform toggles
  • Add an image URL (optional — required for Instagram)
  • Post Now — publishes immediately to all selected platforms
  • Schedule — pick a date/time, post is added to the queue
ℹ️ Instagram requires an image URL — text-only posts are not supported by Instagram's API.

📅 Scheduling Posts

NEXUS checks for due posts every minute and publishes them automatically.

Schedule a post

Compose → click Schedule → pick date/time → click Schedule Post

Bulk scheduling via CSV

Create a CSV file in your CONTENT_FOLDER (default: D:/social):

content,platforms,scheduled_at,image_url
"Your post text","linkedin,facebook","2026-07-01 09:00",
"Another post","instagram","2026-07-02 10:00","https://example.com/img.jpg"

Then: Local Files → Import CSV Schedule

🎨 AI Image & Video Generator

Image Generation

Go to AI Media Creator → Images

  • Requires STABILITY_API_KEY (free credits at stability.ai) or OPENAI_API_KEY
  • 8 style presets: Photorealistic, Cartoon, Anime, Digital Illustration, 3D Render, Watercolor, Sketch, Abstract
  • Use Enhance Prompt to improve your prompt before generating
  • Use → Use in Post to add the image URL to your Compose

Video Generation

Go to AI Media Creator → Video

  • Requires LUMA_API_KEY (30 free/month) or RUNWAY_API_KEY (125 free credits)
  • Text-to-video or Image-to-video (provide an image URL as the starting frame)
  • Video generation takes 30–120 seconds — click Check Status to poll for completion

Animation

Animate a static image into a short video clip:

  1. Generate an image first (Images tab)
  2. Go to Animation tab → paste the base64 image data or image URL
  3. Select motion intensity → click Generate Animation
⚠️ Animation requires STABILITY_API_KEY.

👑 Admin Dashboard

Only visible to users with the Admin role. Access via the sidebar or user menu.

Overview Tab

Shows platform-wide stats: total users, users active today, total posts published, AI generations, and scheduled posts in queue.

🔧 Troubleshooting

Server won't start (EADDRINUSE)

Port 3000 is already in use. Kill existing Node.js processes:

Get-Process node | Stop-Process -Force   # PowerShell
# then restart: npm start

Facebook posting error 403

The stored token is missing pages_manage_posts permission. Solution:

  1. Go to Graph API Explorer
  2. Select your app → User or Page → select your Page name (not User Token)
  3. Add permission: pages_manage_posts
  4. Generate token → copy → Settings → Facebook → Paste token manually

Ollama not responding

  • Ensure Ollama app is open (system tray icon)
  • Or run ollama serve in a terminal
  • Check URL in Settings → Local AI (default: http://localhost:11434)

AI generation returns empty response

  • If using Ollama: model might still be loading. Wait 30 seconds and retry.
  • Check the model is downloaded: ollama list
  • Try switching to a different AI model in the model selector bar

Google AI 404 error

The API version was incorrect. This is fixed in NEXUS v2.0. Restart the server: npm start
